    python3 design/marks/generate_marks.py avatar

shanky.md print, the wordmark and three lines of copy. The card
exists so grain never sits under type below 14px.

Upload avatar-light-460.png at github.com/settings/profile.

BRAND-SURFACES.md; do not upload the dark file unless he says
otherwise. The upload is manual and GitHub caches avatars hard
on its CDN, so verify in a private window, not a normal reload.

profile repo stays ink; carrying copper here is a deliberate
