# GitHub profile avatar

Generated. Do not hand-edit. Rebuild with:

    python3 design/marks/generate_marks.py avatar

Layout: contribution field behind a terminal card holding the
shanky.md print, the wordmark and three lines of copy. The card
exists so grain never sits under type below 14px.

Upload avatar-dark-460.png at github.com/settings/profile. The
upload is manual and GitHub caches avatars hard on its CDN, so
verify in a private window, not a normal reload.

Note: the contribution field is copper. brand-tokens says the
profile repo stays ink; carrying copper here is a deliberate
owner decision recorded in BRAND-SURFACES.md, not a drift.
